# Bookmarks API

Небольшой HTTP API для хранения закладок в памяти процесса. Подходит для изучения Go HTTP-сервера, CRUD и тестирования обработчиков.

## Модель Bookmark

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Положительный идентификатор, назначается сервером |
| `url` | string | Абсолютный URL с `http` или `https` и непустым host |
| `title` | string | Непустое название |
| `tags` | array of strings | Необязательные теги |
| `created_at` | RFC 3339 timestamp | Время создания |
| `updated_at` | RFC 3339 timestamp | Время последнего изменения |

При создании и обновлении сервер удаляет пробелы по краям `url` и `title`. Отсутствующий или пустой массив `tags` допустим; пустые строки и строки из пробелов внутри массива отклоняются. Остальные теги сохраняются без изменений.

## Маршруты

| Метод | Путь | Успех | Возможные ошибки |
| --- | --- | --- | --- |
| `POST` | `/bookmarks` | `201` и созданная закладка | `400` |
| `GET` | `/bookmarks` | `200` и массив закладок | — |
| `GET` | `/bookmarks/{id}` | `200` и закладка | `400`, `404` |
| `PUT` | `/bookmarks/{id}` | `200` и обновлённая закладка | `400`, `404` |
| `DELETE` | `/bookmarks/{id}` | `204`, пустое тело | `400`, `404` |
| `GET` | `/healthz` | `200`, `{"status":"ok"}` | — |

`HEAD` поддерживается для всех `GET` маршрутов. Неизвестный путь возвращает `404`, неподдерживаемый метод на известном пути — `405` с заголовком `Allow`. Успешные ответы с телом и все ошибки имеют `Content-Type: application/json`.

## Запуск

Нужен Go версии, указанной в `go.mod`.

```sh
go run ./cmd/bookmarks-api
```

По умолчанию сервер слушает `:8080`. Адрес можно изменить, например `BOOKMARKS_ADDR=:18080 go run ./cmd/bookmarks-api`. Остановить его можно через Ctrl+C или SIGTERM; активным запросам даётся до 10 секунд на завершение.

## Пример полного CRUD

```sh
curl -i -X POST http://localhost:8080/bookmarks \
  -H 'Content-Type: application/json' \
  -d '{"url":" https://go.dev ","title":" Go ","tags":["docs"]}'

curl -i http://localhost:8080/bookmarks
curl -i http://localhost:8080/bookmarks/1

curl -i -X PUT http://localhost:8080/bookmarks/1 \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://go.dev/doc/","title":"Go documentation","tags":["go","docs"]}'

curl -i -X DELETE http://localhost:8080/bookmarks/1
```

## Ошибки

Тело ошибки всегда имеет форму:

```json
{"error":"описание ошибки"}
```

Например, `GET /unknown` возвращает `404` с JSON-ошибкой. Неверное тело JSON, неизвестные поля, дополнительное значение после объекта, некорректный URL, пустой title, пустой тег и неверный ID возвращают `400`. Размер тела запроса ограничен 1 МиБ.

## Тестирование

```sh
gofmt -w *.go cmd/bookmarks-api/*.go
go vet ./...
go test ./...
go test -race -count=1 ./...
```

## Ограничения

Закладки хранятся только в памяти и исчезают после перезапуска. В этой версии нет постоянной базы данных, авторизации, пагинации и фильтрации.
